# 🧮 Qt Signals & Slots — консольный калькулятор

> Учебный проект: демонстрация механизма **сигналов и слотов** Qt
> в консольном приложении без графического интерфейса.

---

## 🎯 Цель

Изучить механизм сигналов и слотов Qt:

- наследование от `QObject` и макрос `Q_OBJECT`;
- объявление собственных сигналов и слотов;
- соединение через `QObject::connect()`;
- работу MOC в консольном режиме без GUI.

---

## 🏗️ Реализация

| Компонент | Описание |
|-----------|----------|
| **Проект** | Qt Console Application, qmake, модуль `core` (`QT -= gui`, `CONFIG += c++17 console`) |
| **`Validator`** | Наследник `QObject`. Слот `validateNumber` проверяет строку через `QString::toDouble`, при ошибке излучает `validationFailed(QString)` |
| **`Calculator`** | Наследник `QObject`. Слоты арифметики, слоты-обёртки для строк, приватный слот `onValidationFailed` → сигнал `errorOccurred` |
| **`main.cpp`** | `QCoreApplication`, ввод/вывод через `QTextStream`, подписка на сигналы лямбдами |

**Сигналы `Calculator`:**

- `resultReady(double)` — успешное вычисление
- `errorOccurred(QString)` — ошибка валидации или логическая ошибка (деление на ноль, `ln ≤ 0`)
